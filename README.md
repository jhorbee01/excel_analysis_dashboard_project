# Coffee Shop Sales Analysis – Excel Portfolio Project

## Overview

This project uses a coffee shop sales dataset to explore sales performance from January 2019 to August 2022. I used Microsoft Excel to prepare the data, analyse sales trends, compare performance across countries, and identify the top five customers.

## Project Files

- `coffee_shop_raw_data` – The raw data set used for the analysis
- `coffee_shop_final_data` – The prepared dataset used for the analysis.
- `README.md` – Project documentation, including the analysis process and findings.

## Dataset

- 1,000 order records.
- 913 unique customers in the orders data.
- Sales data covering January 2019 to August 2022.
- Three countries: United States, Ireland, and United Kingdom.
- Four coffee types: Arabica, Excelsa, Liberica, and Robusta.

The dataset contains order details, customer information, and product information.

## Cleaning and Preparation

The following tasks were carried out to prepare the data for analysis:

- Used XLOOKUP to retrieve customer details from the Customers table.
- Used INDEX/MATCH to retrieve product information.
- Used IF statements to convert abbreviated coffee type labels into full names.
- Reviewed lookup formulas and corrected reference errors.
- Prepared the order data for analysis using PivotTables.

## Analysis and Findings

The analysis focused on monthly sales by coffee type, sales by country, and the top five customers by sales.

Initial findings include:

- Total sales were **$45,134.26**.
- The United States generated the highest sales, with **$35,638.89**, representing approximately 79% of total sales.
- Ireland generated **$6,696.87** in sales.
- The United Kingdom generated **$2,798.51** in sales.

The top five customers by sales were:

- Allis Wilmore – $317.07
- Brenn Dundredge – $307.04
- Terri Farra – $289.11
- Nealson Cuttler – $281.68
- Don Flintiff – $278.01

## Dashboard

An interactive Excel dashboard was created to present the results.

It includes:

- Monthly sales by coffee type, displayed in a line chart.
- Sales by country, displayed in a bar chart.
- Top five customers by sales.
- A Timeline Slicer for filtering by date.
- Slicers for Roast Type, Loyalty Card, and Size.

These filters allow users to explore the sales data from different perspectives.

## Skills Demonstrated

Microsoft Excel, data cleaning and preparation, XLOOKUP, INDEX/MATCH, IF statements, absolute and relative cell references, PivotTables, PivotCharts, data analysis, data visualisation, interactive dashboards, slicers, and timeline filtering.
